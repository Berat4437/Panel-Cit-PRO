Panel Çit PRO, panel çit ölçüleri, tel adedi ve yaklaşık ağırlık hesaplamalarını hızlı şekilde yapabilen, aynı zamanda teknik çizim oluşturan Java tabanlı masaüstü uygulamasıdır.

Uygulama özellikle panel çit üreticileri, proje çizenler, satış ekipleri ve teknik hesaplama yapan kullanıcılar için geliştirilmiştir.

Özellikler:
-Panel ölçülerine göre otomatik tel hesabı
-Yatay ve dikey tel adedi hesaplama
-Yaklaşık panel ağırlığı hesaplama
-Ölçekli teknik panel çizimi oluşturma
-Göz aralığı gösterimi
-PNG olarak çizim dışa aktarma
-Modern ve sade arayüz
-Klavye Enter geçiş sistemi ile hızlı veri girişi

Kullanılan Teknolojiler:
-Java
-Java Swing
-AWT Graphics2D
-BufferedImage
-Object Oriented Programming (OOP)

-Yatay tel adedi ✓

   -Görsel Çizim Sistemi ✓

-Panel çit çizimini oluşturur ✓
-Ölçü bilgilerini gösterir ✓
-Yatay ve dikey tel yerleşimini çizer ✓
-Teknik görünüm sağlar ✓

Oluşturulan panel çizimi tek tuşla PNG formatında masaüstüne kaydedilebilir.
